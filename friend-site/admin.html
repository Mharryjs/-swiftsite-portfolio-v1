How this panel works

Every change saves by itself about 2 seconds after you stop typing, and then shows for all visitors. Wait for ✓ Live for everyone before you close the page.

Login & security

There is no admin button on the website. This panel opens with Windows + Ctrl + Shift + M or at /admin.html, and it locks again every time you leave it.

The PIN, name and password are written inside admin.html. Anyone who opens the website's files can read them, and anyone who knows the address can reach this login page. The lock keeps casual visitors out, but it is not real security.
